# Overview

This is the third project of my first year at ISART. We had to develop a 2 player one button game on our own in C#. The restriction was that the game had to be on a track with a set path.

You play as 2 little satellites feeding various space objects to a star they're orbiting. Cooperate with your satellite friend to feed it and help the star reach supernova! Use your button to move away from the star and release to be pulled. I made everything except for the music.

**Note:** I was initially given a week for this project but due to some circumstances I only had 3 days to work on it.

## Key Features

- **Gravity System**: Custom gravity mechanics for orbital movement.
- **One Button Controls**: Simple controls where you press to move away from the star and release to be pulled.
- **Path System**: Track-based movement system.
- **Cooperative Multiplayer**: 2-player local and online multiplayer via NodeJS server.
- **Juiciness & Polish**: Animations and sound integration for enhanced game feel.

## My Tasks

- **Gravity system**: Implemented orbital gravity mechanics.
- **Game Concept**: Designed the core game concept.
- **Controls**: Created the one-button control scheme.
- **Path system**: Developed the track-based movement system.
- **Juiciness**: Added game feel polish and animations.
- **Animations**: Created all in-game animations.
- **Sound Integration**: Integrated audio feedback.
- **Online Multiplayer**: Implemented online multiplayer integration in Godot.
- **NodeJS Server**: Built the server for online multiplayer.
