# Overview

I recreated the original Tetris with the modern ruleset. I've always loved Tetris and I already had remade it in the console but I wanted to remake it in a game engine.

This was mainly an excuse to work on, and use my own code library for Unity.

## Key Features

- **Modern Tetris Ruleset**: Implements the contemporary Tetris gameplay mechanics and rules.
- **Controlled Randomness**: Smart piece queue system for fair and balanced gameplay.
- **Juicy Effects**: Line clear animations, screen shake, and visual trails for satisfying feedback.
- **Dynamic Audio**: Music crossfades between levels and line clear sounds pitch up on combos.
- **Score & Combo System**: Complete scoring system with combo multipliers for skilled play.

## My Tasks

- **UI System**: Designed and implemented the complete user interface.
- **Controls**: Programmed responsive keyboard controls for precise piece manipulation.
- **Controlled Randomness**: Implemented the piece queue system with fair randomization.
- **Juiciness**: Added polish with line clear effects, screen shake, and particle trails.
- **Audio System**: Created dynamic music crossfades between levels.
- **Sound Design**: Implemented pitch-shifting line clear sounds that respond to combos.
- **Score & Combo System**: Developed the scoring mechanics and combo tracking.
- **Grid System**: Built the core grid management and collision detection.
- **Visual and Audio Assets**: Created and integrated all visual and audio elements.
