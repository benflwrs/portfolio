# Overview

This is a side project of my second year at ISART. We had to create a fighting game prototype.

As this is an exercise in prototyping, I had to make assets quickly and straight to the point to convey the point of the game as clearly as possible. I made all the of the animations and visual effects and integrated them in Unity through the Animator and such.

Mostly programmed stuff on the game feel side (camera, feedbacks, etc). I designed every visual asset except for the text font.

## My Tasks

- **UI**: Designed and implemented the user interface
- **Juiciness**: Intro sequences, particles, healthbar animations, and game over effects
- **Animations**: All character and effect animations
- **Hitboxes**: Implemented the hitbox/hurtbox system
- **Moves**: Programmed character moves and combos
- **Prototype Textures**: Created visual assets
- **Camera**: Multi-target camera system

# Showcase

## Multi-Target Camera

Implemented a dynamic camera system that tracks both players during the fight, automatically adjusting the zoom and position to keep both fighters visible at all times while maintaining optimal framing.

![Multi-Target Camera System](/projects/prototype/camera.jpg)

## Hitbox/Hurtboxes System

Created a robust hitbox and hurtbox system to handle combat interactions. This system ensures precise hit detection and allows for complex move combinations and counter-play mechanics.

![Hitbox/Hurtbox System](/projects/prototype/hitbox.jpg)

## UI Animations / FX

Designed and animated all UI elements with a focus on visual feedback and game feel. This includes health bars, character intros, hit effects, and victory/defeat screens with particle effects and screen shake.

# Gameplay

The gameplay focuses on fast-paced one-on-one fighting with emphasis on timing, positioning, and combo execution. The prototype served as a proof of concept for the core fighting mechanics and visual feedback systems.
