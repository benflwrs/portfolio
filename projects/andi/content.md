# Overview

This is the second project of my second year at ISART. We had to make a platformer game in Unity 2D.

In this game you have to cross through the beautiful scenery of a small corner of Iceland and discover its secrets. The game features smooth platforming mechanics, a custom UI system, and integrated leaderboard functionality.

## Key Features

- **Beautiful Scenery**: Explore the stunning landscapes of Iceland with carefully crafted environments.
- **Zipline System**: Custom zipline mechanics with a dedicated level editor tool for designers.
- **Save System**: Robust save system to preserve player progress.
- **Leaderboard**: Integrated leaderboard system for competitive gameplay.
- **Multi-Platform**: Supports Controller, Keyboard, and Touch controls.

## My Tasks

- **Game Design**: Contributed to overall game design and mechanics.
- **UI System**: Programmed the complete UI system for menus and HUD.
- **Save System**: Implemented a robust save/load system.
- **Leaderboard System**: Developed the leaderboard integration and display.
- **Zipline Mechanics**: Programmed the zipline traversal system.
- **Level Editor Tool**: Created a custom editor tool for zipline placement and configuration.
